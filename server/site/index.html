Claude Code forgets everything when a session ends. Engram keeps a short record of what you did and hands it back the next time you open the project.

While you work

Engram notes your prompts, the files Claude edits and the commands it runs. Anything that looks like a password or API key is blanked out before it leaves your machine.

When the session ends

Claude writes itself a few lines on what changed, what was decided and what's left to do. This runs on your own Claude plan.

Next time

A new session in that project starts with those notes. Ask Claude to search your memory and it can dig up older ones from any project.
